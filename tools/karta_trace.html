Управление

Ставь точки только там, где можно стоять: по осевой линии коридоров и в центрах комнат. Стены не рисуются.

Клик по пустому месту — новая точка; если была выделена точка, они соединяются текущим типом. Так коридор ведётся ломаной.

Клик по точке — соединить с выделенной (или выделить).

Клик по линии при выделенной точке — развилка: линия делится, новая точка соединяется с выделенной. Shift+клик по линии — просто разделить.

Esc — закончить ломаную (снять выделение).

R или двойной клик по точке — номер комнаты (1–41 или слово: «колодец», «лифт»).

N — заметка к точке или линии.

1–6 — тип перехода; при выделенной линии меняет её тип.

Delete — удалить выделенное. Ctrl+Z — отменить.

Перетаскивание точки — сдвинуть. Колесо — масштаб. Правая или средняя кнопка — двигать карту.

Тупик отмечать не нужно: точка с одной линией подсвечивается сама.

Всё сохраняется в браузере автоматически. В конце — «Экспорт JSON».
